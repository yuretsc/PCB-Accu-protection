Плата захисту акумулятора
Універсальна плата захисту для акумуляторів з напругою 4–36 В і струмом навантаження до 4 А.
При встановленні транзисторів 60N06 максимальний струм збільшується до 9 А. Передбачена можливість підключення додаткового охолодження.

Роз'єми
ВХІД — підключення акумулятора.
ВИХІД — підключення споживача.
КНОПКА — підключення кнопки зовнішнього запуску.
ВОЛЬТМЕТР — підключення зовнішнього вольтметра для контролю напруги акумулятора.

Функції захисту
Захист від розряду. При зниженні напруги акумулятора до нижнього порогу плата автоматично відключає споживача.
Захист від перезаряду. При підвищенні напруги акумулятора вище верхнього порогу під час заряджання плата автоматично відключає споживача.

Керування
Підключення споживача виконується виключно зовнішньою кнопкою через роз'єм КНОПКА.
